# TRAKS

A tiny, cozy 2D survival farming game built with Godot 4.7, C++, and Python.

Author: Jaiyshaan

Theme: Dark purple with subtle glowing accents.
Features: Procedurally generated terrain, AI villagers, crop growth system, keyboard controls, and multi-platform game downloads.

## Development

Prerequisites: Node.js (>= 20) and npm/bun.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Deploy to Firebase

```sh
firebase login
firebase deploy
```
